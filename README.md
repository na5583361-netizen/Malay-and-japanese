# Malay-and-japanese
# マレーシア語（マレー語）学習ツール

このプロジェクトは、マレー語の日常単語を学習するためのシンプルなWebアプリケーションです。HTML、CSS、JavaScriptのみで構成されており、サーバーの構築やデータベースの設定なしで、ブラウザ上でそのまま動作します。

## ✨ 主な機能

1. **日常単語リスト & 音声再生**
   - 頻繁に使うマレー語の単語、発音（カタカナ）、意味を一覧表示します。
   - 「🔊」ボタンを押すと、ブラウザ標準の音声合成機能（Web Speech API）を利用してネイティブに近いマレー語の発音を読み上げます。

2. **リスト内検索機能**
   - 単語リストの上部にある検索ボックスに文字を入力すると、マレー語や日本語の意味でリストを即座に絞り込みます。単語が増えてもすぐに探し出せます。

3. **即座翻訳機能 (日本語 → マレー語)**
   - 入力欄に日本語を打ち込むと、自動的にマレー語に翻訳されます。
   - 入力が完了して少し待つと（約0.8秒後）自動で翻訳処理が走るため、翻訳ボタンを押す手間がかかりません。
   - 翻訳結果も「🔊 音声を聞く」ボタンから発音を確認できます。

## 📁 ファイル構成

- `index.html`: Webページのメインとなる構造ファイル。ここからCSSとJSを読み込みます。
- `style.css`: ページ全体のデザイン、レイアウト、スマートフォン向けのレスポンシブ対応を設定しています。
- `script.js`: 自動翻訳機能、検索フィルタリング、音声再生を制御するプログラムです。
- `README.md`: このプロジェクトの概要と使い方をまとめたファイルです。

## 🚀 使い方（ローカルでの実行）

1. `index.html`, `style.css`, `script.js` の3つのファイルをすべて同じフォルダ内に配置します。
2. `index.html` をダブルクリックするか、Google Chrome、Safari、EdgeなどのWebブラウザにドラッグ＆ドロップして開きます。
3. （Webサイトとして公開する場合は、FTPソフトなどを使ってWebサーバーにこのフォルダごとアップロードしてください）

## 📝 単語リストの追加方法

新しい単語を追加したい場合は、`index.html` をテキストエディタ（メモ帳やVS Codeなど）で開きます。
ファイルの後半にある `<tbody>` から `</tbody>` の間に、以下のHTMLコード（行のブロック）を追加して内容を書き換えてください。

```html
<tr>
    <td>マレー語のスペル</td>
    <td>カタカナ発音</td>
    <td>日本語の意味</td>
    <td><button class="play-btn" data-text="読ませたいマレー語">🔊</button></td>
</tr>
```

## ⚠️ 注意事項

- **音声再生について**: お使いのOSやブラウザがマレー語（`ms-MY`）の音声エンジンを搭載していない場合、音声が出ない、もしくは英語なまりで再生されることがあります。iOS/Androidの最新OSや、Windows/Macの主要ブラウザであれば基本的には対応しています。
- **翻訳機能について**: 無料で利用できるパブリック翻訳API（MyMemory API）を利用しています。大量の長文を短時間に連続して翻訳しようとすると、一時的な利用制限がかかる場合があります。
